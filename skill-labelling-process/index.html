Skill labelling: the new process

How each video-benchmark question now gets its skill labels (L1 › L2 › L3). Piloted on 300 questions from 27 benchmarks, 2026-11-04. The labeller never sees the video: it works from the question, the options and the correct answer.

Process

1 · Plan, then look up (labeller)

Claude Sonnet 5.5, 5 questions per call

For each question the labeller writes the step-by-step plan someone watching the video would follow to reach the correct answer, one skill per step, with the evidence each step uses. It then looks each step's skill up in the skill ledger: it cites an existing L2 › L3 node, or proposes a new one (NEW L2 / NEW L3) with its nearest existing node and how it differs.

↓

2 · The ledger

a tree with fixed node IDs and exactly one parent per node

It starts empty and grows during labelling. Labellers see a frozen snapshot of it (names + one-line definitions) during each epoch. There is no L1 level during labelling: L2s sit under a hidden root, so no top-level category is primed.

↓

3 · Curator, after every epoch

Claude Sonnet 5.5, one call per epoch

Decides each proposal: accept it as a new node (with a general name and a definition that says how it differs from its nearest sibling) or merge it into a node that means the same skill. Questions labelled with a merged proposal follow it to the surviving node.

↓

4 · Blind parent judges, after every epoch

3 Claude Sonnet 5.5 judges, majority of 2 of 3

Each new L3 is placed under an L2 by three judges who see shuffled candidates under random codes, with no node IDs, current parent or votes. 2 of 3 agreeing on a different parent moves the node; at two re-judge epochs every L3 is checked again. Validated on planted misplaced nodes: 111/112 L3s placed correctly.

↓

5 · L1s induced after labelling

3 independent Claude Sonnet 5.5 inducers + 1 naming call

Once all questions are labelled, each inducer groups the final L2s into broad categories (no target count, no catch-all category). The three groupings are combined by consensus (average-linkage on co-assignment, merge above 0.5), and a naming call names and defines each group. Agreement between inducers is reported as ARI.
