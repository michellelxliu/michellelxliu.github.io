Setup

Encoder
gte-modernbert-base @ e7f32e3c (149M), full fine-tune, CLS pooling
Input
question text + answer options (no video)
Labels
20 most common raw L1 skill names (99.0 % of label instances), multi-label; no merging of names
Loss
sigmoid question–label contrastive loss with learned temperature and bias (term weight w = 1, chosen by a 1-epoch sweep over w ∈ {0, 0.5, 1, 2})
Data
70,975 labelled questions: train 55,556 · val 6,681 · test 8,108 (test benchmarks: motionbench, next-qa, timeblind, tomato)
Training
batch 64, AdamW 2e-5, ≤ 5 epochs, validation every 200 steps, early stop on val macro-AP (patience 5); stopped after step 3,199, best step 2,199 (val macro-AP 0.533)
Arms
base = untrained encoder; step_N = checkpoints; best = step 2,199; best_stem / best_opts = best model given only the question stem / only the options
Compute
FASRC gpu_test, A100 MIG 3g.20gb, 53 min (training 49.5 min); evaluation on CPU, 3.7 min (E1) + 7.1 min (E2); $0
Scoring
all metrics within benchmark, averaged; 95 % CIs from a bootstrap over source videos, paired across arms

Metric definitions

AUROC / AP
zero-shot: cosine between the question embedding and each label's learned vector, scored per label within each benchmark, then averaged
probe AUROC
logistic-regression probe on frozen embeddings (15,000 training questions)
F1 at bias / val-tuned
set prediction thresholded at the loss's learned bias, or at a threshold tuned on validation; micro / macro over labels
exact set
share of test questions whose predicted L1 set equals the labelled set
MAP@R, R-Prec
retrieval of questions with the identical L1 set, within benchmark
kNN@10 Jaccard
mean Jaccard between a question's L1 set and those of its 10 nearest neighbours (same video masked); “w/o VR” drops Visual Recognition; random baseline in brackets
same-bench share
share of the 10 nearest neighbours from the same benchmark
uniformity
Wang & Isola uniformity of embeddings (more negative = more spread)
bench-ID
accuracy of a probe that predicts the benchmark from the embedding (majority-class baseline in brackets)
control / selectivity
probe on randomly assigned same-size groups; selectivity = probe − control
CLP
k-means on training embeddings, held-out questions assigned to the nearest centroid, scored by the group's rate in that cluster
CPCC
correlation between embedding distances of L1/L2 node means and their distance in the label tree
